# Cyber Freedom Hunt

Design a modern, interactive and visually impressive landing page for a college Computer Science forum event called “CYBOTIXX – Code Freedom Hunt”, conducted as a special Independence Day celebration.

Theme:

Indian Independence Day + Cybersecurity + Coding + Technology. The design should creatively combine the Indian Tricolour (saffron, white and green), Ashoka Chakra, digital/cyber elements, coding symbols, circuit patterns, glowing futuristic effects, and subtle cybersecurity visuals. Keep it patriotic, professional, energetic and suitable for a college technical forum.

Hero Section:

Display a prominent heading:

“WELCOME TO CYBOTIXX”

Below it, display:

“CODE FREEDOM HUNT”

Add a short tagline:

“Decode. Solve. Explore. Celebrate Freedom.”

Add supporting text:

“An Independence Day Special Cyber & Coding Challenge”

Include a visually attractive digital representation of the Indian Tricolour with a glowing Ashoka Chakra integrated into a futuristic cybersecurity/coding environment.

Add subtle animated elements such as:

- Floating code symbols

- Binary numbers

- Circuit lines

- Digital particles

- Lock and shield icons

- Encryption/cipher symbols

- Tricolour light effects

Primary CTA:

A large, highly visible button in the center:

“🇮🇳 START NOW”

The button should have a modern glowing/hover animation and clearly indicate that clicking it starts the Code Freedom Hunt.

Add a small section below the button:

“5 Stages • 50 Challenges • Easy to Hard”

Show the five stages visually:

Stage 1 – Freedom Quiz

Stage 2 – Freedom Puzzles

Stage 3 – Break the Cipher

Stage 4 – Cyber Detective

Stage 5 – Freedom Finale

Design Style:

- Modern futuristic cyber interface

- Clean college-event aesthetic

- Dark navy/black background with tasteful saffron, white and green highlights

- Glassmorphism cards

- Subtle neon glow

- Smooth animations

- Responsive design for desktop, tablet and mobile

- Avoid excessive visual clutter

- Maintain excellent readability

Overall feeling:

The landing page should feel like entering a special “cyber mission” for India's Independence Day. It should immediately make students excited to click “START NOW” and begin the CYBOTIXX Code Freedom Hunt.
Create a fully functional, polished, responsive interactive webpage for:

🇮🇳 CYBOTIXX – CODE FREEDOM HUNT
STAGE 1 — FREEDOM QUIZ

This is the first stage of a CYBOTIXX Independence Day Special technical event. The overall event combines Indian Independence Day, coding, cybersecurity, logical thinking and technology.

5. QUESTIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Use exactly these questions and answers:

QUESTION 1

What does CPU stand for?

A. Central Processing Unit
B. Computer Personal Unit
C. Central Program Utility
D. Computer Processing User

Correct Answer:
A. Central Processing Unit

Explanation:
The CPU is the primary processor responsible for executing instructions and performing calculations.


QUESTION 2

Which of the following is the strongest password?

A. india123
B. password2026
C. Jyothi123
D. C@7m!Q9#xL2

Correct Answer:
D. C@7m!Q9#xL2

Explanation:
A strong password uses a combination of uppercase and lowercase letters, numbers and special characters.


QUESTION 3

What does HTTPS provide compared with HTTP?

A. Faster internet speed
B. Encrypted communication
C. More storage
D. Free internet access

Correct Answer:
B. Encrypted communication

Explanation:
HTTPS uses encryption, typically through TLS, to protect data exchanged between a browser and website.


QUESTION 4

Which of these is a programming language?

A. Python
B. HTML
C. Wi-Fi
D. USB

Correct Answer:
A. Python

Explanation:
Python is a general-purpose programming language widely used in software development, automation, data science and AI.


QUESTION 5

What is phishing?

A. A method of increasing internet speed
B. A cyberattack that tricks users into revealing sensitive information
C. A programming technique
D. A method of compressing files

Correct Answer:
B. A cyberattack that tricks users into revealing sensitive information

Explanation:
Phishing commonly uses fake emails, messages or websites to trick people into providing passwords, financial information or other sensitive data.


QUESTION 6

Which device connects different networks and forwards data between them?

A. Keyboard
B. Monitor
C. Router
D. Printer

Correct Answer:
C. Router

Explanation:
A router connects networks and forwards data packets toward their destination.


QUESTION 7

What does AI stand for?

A. Automated Internet
B. Artificial Intelligence
C. Advanced Information
D. Applied Internet

Correct Answer:
B. Artificial Intelligence

Explanation:
Artificial Intelligence refers to computer systems designed to perform tasks that normally require human-like intelligence.


QUESTION 8

Which Indian organization is responsible for India's space programme?

A. DRDO
B. ISRO
C. RBI
D. UIDAI

Correct Answer:
B. ISRO

Explanation:
ISRO stands for Indian Space Research Organisation and is responsible for India's space programme.


QUESTION 9

India celebrates Independence Day on:

A. 26 January
B. 15 August
C. 2 October
D. 14 November

Correct Answer:
B. 15 August

Explanation:
India celebrates Independence Day every year on 15 August, commemorating independence from British rule in 1947.


QUESTION 10

Which of the following is the safest action when you receive a suspicious email asking for your password?

A. Click the link immediately
B. Reply with your password
C. Verify the sender through an official channel and report/delete the message
D. Forward it to everyone

Correct Answer:
C. Verify the sender through an official channel and report/delete the message

Explanation:
Never provide passwords through suspicious links or messages. Verify requests through trusted official channels.
